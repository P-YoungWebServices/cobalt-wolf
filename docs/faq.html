FAQ

Frequently asked questions

Can't find your answer? Check the wiki or open an issue.

Is Cobalt Wolf free?

Yes — completely. Cobalt Wolf is free and open-source software licensed under GPL v3. Every feature is included; there are no paywalls, ads, tracking or premium tiers.

What do I need to use it?

A Jellyfin server running 12.0 or newer and an Android device on Android 7.0+. The same APK works on phones, tablets, Android TV and Fire TV.

Is this an official Jellyfin app?

No. Cobalt Wolf is a third-party client and is not affiliated with or endorsed by the Jellyfin project. It's built on the official Jellyfin Kotlin SDK.

Does it support Emby?

No — Cobalt Wolf is Jellyfin-only by design.

Will it direct-play my 4K HDR files?

If your device can decode them, yes. Cobalt Wolf probes the device's decoders, display and audio output each time playback starts and picks the best supported path: H.264, HEVC, AV1 and VP9 up to 4K; HDR10, HDR10+, HLG and Dolby Vision (profiles 5, 7, 8). If a format isn't supported it falls back — first to on-device FFmpeg decoding, then to a server transcode — instead of failing. See the playback wiki page for the exact fallback order.

Does it do audio passthrough (Atmos, DTS:X)?

Yes — Dolby Digital, Digital Plus/Atmos, TrueHD/Atmos, DTS and DTS-HD MA/DTS:X are passed through when the connected HDMI sink reports support for the format. Otherwise audio is decoded to PCM on-device. There's also a night mode / loudness normalization option.

How does the TV version work?

There's one APK. On a device that reports itself as a television (Android TV, Fire TV, Google TV), Cobalt Wolf automatically swaps to a dedicated 10-foot interface with D-pad navigation, remote transport keys, frame-rate matching and home-screen channels where the platform supports them. See the TV wiki page.

Why can't I see the admin dashboard?

Admin features are gated by your Jellyfin user policy — only users with the administrator flag see the management sections (sessions control, users, tasks, logs, media manager, downloads). Regular users still get a reduced dashboard with recently added media. Ask your server admin to check your account's permissions.

Which companion services does it integrate with?
  • Seerr / Jellyseerr — discovery, requests, approval queue
  • Radarr & Sonarr — calendars plus a full media manager
  • qBittorrent — live transfer monitor and control
  • Bazarr — wanted subtitles and provider search
  • Prowlarr — indexer health, stats and retests

All of them are optional — enter a URL and API key (or credentials for qBittorrent) in the app's service settings. API keys are stored encrypted via the Android Keystore.

Can I use more than one server or account?

Yes. Cobalt Wolf saves server profiles and lets you switch between servers and accounts without signing out. Tokens are stored per-profile in the Android Keystore and excluded from backups.

Is there an iOS version?

Not yet. The business logic lives in a Kotlin Multiplatform shared module specifically so an iOS app can be added later, but Android is the only shipping platform today.

Where is it distributed?

As an APK — directly from this site or from GitHub Releases — or build it yourself from source. It's currently in beta; Play Store / Amazon Appstore distribution is still an open decision. Only install APKs from this site, the official releases page or your own builds.

Something's broken — where do I report it?

First check the troubleshooting page. If it's still broken, open a GitHub issue with your device model, Android version, Jellyfin server version and what you were playing.
