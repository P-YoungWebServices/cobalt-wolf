Feature overview

Everything Cobalt Wolf does

Cobalt Wolf is three apps in one: a media player, a server admin console and a media-management toolkit. Here's the full list.

Watching

Library browsing

  • Movies, series, music, live TV, home videos, music videos and mixed libraries
  • List/card views, card sizes and image-type choices
  • Continue Watching, Next Up, Recently Added, suggestions and upcoming rows
  • Global Favorites page

Detail pages

  • Movies, episodes, series, seasons, people, artists and albums
  • Cast & crew, chapters, media info and related items
  • Video quality and audio profile summaries

Playback control

  • Audio and subtitle track pickers
  • Version / media source selection
  • Playback speed and repeat modes
  • Play Next, Add to Queue, Play All From Here, shuffle
  • Resume and play-from-start

Playlists & collections

  • Create, reorder and manage items
  • Multi-select mode and long-press context menus
  • Share / copy stream URL
  • Media deletion and admin metadata tools

Music

  • Audio playback with a now-playing experience
  • Music mixes and synced lyrics

Live TV

  • Channel browsing and playback
  • EPG guide
  • Recording management

Search

  • Searches your library and Seerr at once
  • Filter chips: type, genre, rating, runtime, year, play state, quality, features

Offline

  • Downloads for offline playback on phone and tablet

Watch together

  • SyncPlay groups — play, pause and seek in sync with friends
  • Start a group from any detail page

High-end playback

Video

  • H.264, HEVC, AV1 and VP9 up to the device's decoder limits — 4K where available
  • HDR10, HDR10+, HLG and Dolby Vision (profiles 5, 7 and 8) when decoder and display support them
  • Unsupported Dolby Vision falls back to its HDR10/HLG/SDR base layer; HDR10+ falls back to HDR10; HDR on an SDR display is tone-mapped by the server

Audio

  • Dolby Digital, Digital Plus (incl. Atmos), TrueHD (incl. Atmos), DTS and DTS-HD MA (incl. DTS:X) passthrough when the HDMI sink reports the format
  • Otherwise decoded to PCM on-device
  • Night mode / loudness normalization for late-night listening

Fallback chain

  • Direct play → local FFmpeg software decoding → server transcode
  • Configurable codec preference and codec-level caps
  • A decoder that fails mid-playback moves down the chain and resumes where it stopped

Subtitles & tools

  • Styled ASS/SSA via libass, plus PGS and SRT
  • Per-track delay offset for external text subtitles
  • Stats overlay: codec, bitrate, HDR type, audio output, sample rate, channels, dropped frames
  • Gesture controls (brightness, volume, seek) and trickplay seek thumbnails
  • Playback settings page listing detected capabilities with manual overrides

Server admin dashboard

Available to Jellyfin administrators; everyone else gets a reduced view with recently added media.

Sessions

  • Real-time active sessions with per-user activity
  • Session details: who, what, progress, codecs, transcoding
  • Playback control and messages to sessions
  • Home-screen widget listing live sessions

Management

  • User management: view, create, edit, delete
  • Device management
  • Libraries, plugins and server settings pages

Monitoring

  • Scheduled tasks: start, stop, monitor
  • Live server logs with filters
  • Activity log and API key administration
  • System info and update status

Multi-server

  • Save profiles for several servers and accounts
  • Switch without signing out — tokens stored in Android Keystore

Request queue

  • Approve or decline Seerr requests
  • Notifications for request events

Sign-in

  • Username/password and Quick Connect
  • Role detection from the Jellyfin user policy — admin routes stay hidden for viewers

Requests, calendar & media management

Seerr / Jellyseerr

  • Browse trending and popular titles
  • Request movies and series, with season selection
  • Track your own requests: pending, approved, available, declined
  • Sign in with your Jellyfin account

Calendar

  • Upcoming episodes and releases from Radarr and Sonarr
  • List, week and month views

Media manager (admin)

  • Browse Radarr movies and Sonarr series
  • Edit monitored status, quality profile, root folder, tags
  • Season/episode monitoring, rename files
  • Interactive release search + grab, manual import, delete

qBittorrent

  • Live transfer monitor, refreshed every few seconds
  • Pause/resume torrents (v5 and legacy API)
  • Alternative speed-limit toggle

Bazarr

  • Wanted subtitles list
  • Search providers and download a subtitle for a movie or episode

Prowlarr

  • Indexer overview, stats and health
  • Per-indexer retest and test-all

Android TV & Fire TV

10-foot UI

  • Dedicated Compose for TV interface, always dark navy
  • Persistent top bar: Home, Search, Seerr, Calendar, More
  • Autofocus, focus restoration and scroll-to-top tuned for remotes

TV playback

  • Frame-rate matching and HDR signalling on TV
  • Remote transport keys mapped
  • Skip-intro button auto-focused when a segment plays
  • Next-episode auto-advance; "Ends at" wall-clock

Platform integration

  • Home-screen channels for Continue Watching and Recently Added (where the TV provider exists)
  • Deep links: cobaltwolf://item/<id>
  • Admin screens reachable via D-pad as pushed routes
