Android TV & Fire TV

One APK, two interfaces. When Cobalt Wolf runs on a device that reports itself as a television, it automatically loads a dedicated 10-foot UI built with Compose for TV — a different layout, navigation model and player overlay, sharing all the same ViewModels and logic.

Layout & navigation

  • Persistent top bar — the wolf icon plus Home, Search, Seerr, Calendar and a More menu (My requests, Servers, Settings, Server dashboard for admins, Sign out).
  • Always dark — the TV theme is a fixed dark navy palette; it never uses the device's dynamic colours.
  • D-pad focus model — autofocus on screen load, focus restoration when you go Back, and scroll-to-top behaviour tuned for remotes.
  • Watch together isn't a nav item — it lives on detail pages, same as on phone.
  • Back behaviour — pops pushed screens first, returns to Home, then exits.

Text entry with a remote

Text fields stay read-only until you focus them and press centre/enter — then the on-screen keyboard appears. No accidental keyboard popups while scrolling.

Signing in on a TV is much easier with Quick Connect: enter the code from any signed-in Jellyfin client instead of typing a password with the D-pad.

Browsing

  • Poster rows and grids navigated entirely by D-pad.
  • Context menus on every card (menu button or long-press): play, mark watched, favourite, add to queue and more — scoped to the item under focus.
  • Detail pages get a backdrop masthead and an icon action bar mirroring the phone layout.
  • Playlist reordering, the play queue and album track lists are all designed for the remote.

TV playback

  • Remote transport keys — play/pause, fast-forward, rewind and stop are mapped.
  • Focus-aware overlay — controls get a white ring + fill on focus; play/pause is focused when controls appear.
  • Frame-rate matching — the display's refresh rate switches to match the content, and HDR is signalled only while HDR content plays.
  • Skip intro/outro — the skip button auto-focuses when a segment is playing.
  • Next episode — auto-advances at the end of an episode, and a controller next button once the next item resolves.
  • "Ends at" — a wall-clock time in the overlay corner.
Picture-in-picture is deliberately disabled on TV — Fire OS declares the feature but Home → PiP behaves incorrectly there.

Home-screen channels

On devices with the Android TV provider, Cobalt Wolf publishes Continue Watching and Recently Added channels to the launcher home screen. Selecting a program deep-links straight into the item's detail page (cobaltwolf://item/<id>). Devices without the TV provider — including Fire TV — simply skip this.

Admin on TV

Admin features aren't separate TV screens — the phone admin screens run as pushed routes and are fully D-pad navigable. Downloads and service credentials are admin-only routes opened from the Server dashboard.

Fire TV notes

  • Install over network adb or a downloader app — see the download page.
  • Enable Developer options → ADB debugging and Apps from unknown sources for sideloading.
  • Home-screen channels are not available on Fire TV (no TV provider); everything else works.
