Admin dashboard

Cobalt Wolf doubles as a Jellyfin admin console. If your Jellyfin user policy has the administrator flag, the dashboard and management destinations unlock automatically — no separate app, no extra sign-in.

Who sees what

  • Admins get the full dashboard: sessions poll, service cards, management section.
  • Everyone else gets a reduced dashboard — Servers/Playback cards and recently added media, without admin data.
  • Admin routes are hidden and unreachable for non-admins — they're not merely greyed out.

Active sessions

  • Real-time list of who's playing what, with per-user activity.
  • Session detail: item, progress, codecs, whether it's direct-playing or transcoding.
  • Playback control over sessions and the ability to send a message to one.
  • Sessions live on their own page from the dashboard's action cards.

Home-screen widget

An Android home-screen widget lists the server's active sessions — user, item and progress — without opening the app. Add it from your launcher's widget picker.

Management

  • Users — view, create, edit and delete accounts.
  • Devices — review and manage devices that have connected.
  • Libraries — library details and info.
  • Plugins — plugin management and server settings pages.
  • API keys — administration of the server's keys.

Monitoring

  • Scheduled tasks — start, stop and monitor library scans and other jobs.
  • Live server logs — stream the log with filters.
  • Activity log — server activity history.
  • System info & update status.

Service cards

If Seerr, Radarr/Sonarr, qBittorrent, Bazarr or Prowlarr are configured, the dashboard carries status cards for them — including live badge counts for things like Bazarr wanted subtitles and Prowlarr indexer issues.

Notifications

While signed in, a watcher polls for request events and posts local notifications — e.g. when a request is approved or becomes available.

On TV

The dashboard opens from the More menu's Server dashboard entry. Admin screens run as pushed routes that are fully navigable by D-pad; Downloads and service credentials are admin-only routes opened from the dashboard.
