Building from source

Cobalt Wolf is a Kotlin Multiplatform project: a shared module (models, data sources, repositories, ViewModels) plus an Android app module with a Compose UI for phones and a Compose for TV UI for televisions.

Requirements

ToolVersion
JDK17 or newer (Android Studio's bundled JBR works)
Android SDKPlatform 37 — via ANDROID_HOME or local.properties sdk.dir
GradleWrapper included — no install needed

Clone & build

git clone https://github.com/P-YoungWebServices/cobalt-wolf.git
cd cobalt-wolf

./gradlew assembleDebug     # → app/build/outputs/apk/debug/
./gradlew assembleRelease   # → app/build/outputs/apk/release/
./gradlew test              # shared JVM + Android host tests and app unit tests

Install the debug APK on a connected device with:

adb install app/build/outputs/apk/debug/app-debug.apk

Release signing

Release builds sign themselves when keystore.properties exists in the repo root:

storeFile=../release.keystore
storePassword=…
keyAlias=…
keyPassword=…

Copy keystore.properties.example, point it at your keystore, and keep it out of version control (it's gitignored, as are *.keystore/*.jks). Without the file, assembleRelease produces an unsigned APK.

Debug credentials seeding (optional)

Debug builds can auto-configure a test server and service credentials at startup via dev.credentials.properties (gitignored) in the repo root. It seeds Jellyfin sign-in and the Seerr/arr/qBittorrent settings so a fresh test install is usable immediately. Release builds never read it — the release code path is a no-op.

Never commit credentials or copy them into code, docs or issue reports.

Testing playback from adb

Debug builds export two extra entry points (absent from release builds) for testing without a full server:

APP=com.pyoungws.cobaltwolf
# Play a URL directly
adb shell am start -n $APP/.player.DebugPlayerActivity -d http://host:8089/sample.mkv --ez stats true
# Play a library item by id
adb shell am start -n $APP/.player.DebugPlayerActivity --es item_id <jellyfin item id>
# Playback settings screen
adb shell am start -n $APP/.ui.settings.DebugPlaybackSettingsActivity
# Watch the player log
adb logcat -s CobaltWolfPlayback

The CobaltWolfPlayback tag logs detected capabilities, fallbacks taken and a periodic stats line.

Contributing

  • Kotlin only, MVVM + repository layer, coroutines/Flow — no callbacks or RxJava.
  • Small, focused PRs; unit tests for all business logic.
  • Run ./gradlew test before submitting.
