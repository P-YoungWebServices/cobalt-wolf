Multiple servers & accounts

Cobalt Wolf saves a profile for every server/account combination you sign into. Switch between them in seconds — no signing out, no re-entering credentials.

Adding profiles

  • Sign in to a server and it becomes a saved profile automatically.
  • Open the Servers screen (phone: top-bar More menu; TV: the Servers entry in the More menu) to add another server or a different account on the same server.
  • Each profile stores its own session token, so switching never logs the other profile out.

Switching

Tap a profile to swap the active session. The whole app — libraries, dashboards, requests, service settings — reloads against that server. Your admin status is re-evaluated per server: you can be an admin on one and a viewer on another.

Security

  • Profiles are stored with Android Keystore AES-GCM encryption, the same scheme used for the main session.
  • Profile storage is excluded from device backups — tokens never leave the device in plaintext.
  • Removing a profile or signing out drops its stored credentials completely.

Removing profiles

  • Remove profile — drops a saved server/account you're not currently using.
  • Sign out — ends the active session and removes that profile.
  • If a server invalidates your token, the profile is dropped automatically and you're asked to sign in again.
