Getting started

From a fresh install to playing your first item in a few minutes.

1. Check the requirements

RequirementMinimum
Jellyfin server12.0 or newer
Android7.0 (API 24) or newer — phone, tablet, Android TV or Fire TV
NetworkThe device must be able to reach the server (local network or a reachable external address)

2. Install the app

Download the APK directly from this site or from GitHub Releases and open it, or install over adb:

adb install cobalt-wolf-v0.1.0-beta.apk          # USB
adb -s <tv-ip> install cobalt-wolf-v0.1.0-beta.apk  # Android TV / Fire TV over the network

The download page has step-by-step instructions for phones and TVs.

3. Connect to your server

On first launch, Cobalt Wolf asks for your Jellyfin server address. Enter it as a full URL:

  • http://192.168.1.10:8096 — typical local address
  • https://jellyfin.example.com — a remote server behind HTTPS
The address is normalized for you — a bare hostname or IP gets the default port and scheme applied automatically.

4. Sign in

Two ways in:

  • Username and password — your normal Jellyfin credentials.
  • Quick Connect — start Quick Connect in the app, then approve the code from any signed-in Jellyfin client (e.g. the web UI) under Dashboard → Quick Connect. Useful on TVs where typing is painful.

Your access token is stored in the Android Keystore (AES-GCM encrypted), not in plain text, and is excluded from device backups.

5. What you see next

  • Phone/tablet: a bottom-nav layout with your library rows — Continue Watching, Next Up, Recently Added.
  • TV: the 10-foot interface loads automatically with a persistent top bar. Nothing to enable.
  • Admins: if your Jellyfin user policy has the administrator flag, the dashboard and management destinations appear automatically.

6. Optional: connect services

Open More → Services (phone) or the service settings entry on TV to add:

  • Seerr — for discovery and requests (signs in with your Jellyfin account)
  • Radarr / Sonarr — URL + API key, for the calendar and media manager
  • qBittorrent — URL + username + password, for the downloads monitor
  • Bazarr / Prowlarr — URL + API key

All service credentials are encrypted at rest. See Requests and Calendar & media manager for details.
