Media suite installer

OneClick Media Suite is an optional companion project that turns a fresh Ubuntu 24.04+ machine into a complete media automation server — the exact backend Cobalt Wolf's features are built around.

You do not need it. Cobalt Wolf works with any Jellyfin server 12.0+ and any existing Seerr/Radarr/Sonarr/qBittorrent/Bazarr/Prowlarr setup you already run — on a NAS, a VM, TrueNAS, docker-compose files you wrote yourself, whatever. The installer just gets you from zero to a compatible, correctly-wired stack in one shot if you don't have one yet (or want a clean rebuild).

What you get

The value isn't the apps themselves — anyone can spin up containers. It's that the stack arrives already wired together, in the configuration Cobalt Wolf's features are designed around:

  • Requests that fulfil themselves. Browse and request a title in the app (or Seerr's web UI); approval routes it to Radarr or Sonarr, which search the indexers Prowlarr synced in, hand the download to qBittorrent, and import the finished file — typically without you touching a single settings page.
  • Instant library updates. Downloads land in a shared /data layout with per-app categories and hardlink imports — no copying, no duplicated disk space — and Jellyfin's realtime file monitoring picks new media up the moment it arrives, no library scan needed.
  • A dashboard for the box. A Homepage instance behind an authenticated nginx proxy gives you a single page for every service's health and links.
  • Downloads behind a VPN — or not. qBittorrent and Prowlarr can run inside a Gluetun tunnel (AirVPN/WireGuard, generic WireGuard or OpenVPN), and Deunhealth watches the tunnel and restarts the dependent apps if the network namespace drops or changes. An explicit no-VPN mode connects directly if you prefer.
  • The app just works. The installer closes by sideloading the latest Cobalt Wolf release APK to your Fire Sticks and Android devices — bundled in the offline installer and ISO, so it works without internet too.
  • Repeatable. The installer is idempotent — re-run it to repair or update an install, re-run just the wiring phase, or re-do only the app deployment.

What it installs

Docker Engine, then a wired compose stack:

  • Jellyfin — media server, with Movies + TV libraries and realtime monitoring enabled
  • Seerr — request/discovery front end (the service the app's request features use)
  • Prowlarr → Radarr + Sonarr — indexers synced into the media managers automatically
  • qBittorrent — download client with per-app categories (radarr, tv-sonarr) and hardlink-friendly /data layout
  • Bazarr — subtitles
  • Gluetun + Deunhealth — optional VPN tunnel (WireGuard or OpenVPN) for qBittorrent/Prowlarr, with self-healing, or a no-VPN mode
  • Homepage dashboard behind an authenticated nginx proxy

All apps are wired to each other by their API keys at install time — Seerr talks to Radarr/Sonarr, Prowlarr feeds them indexers, downloads import into Jellyfin. Everything the app expects is working from minute one.

Three ways to install

Online installerinstall.sh — downloads the latest images. Default. Offline installerbundle.sh + install.sh — images and Docker debs ship in the folder. Bootable ISObuild-iso.sh — Ubuntu Server installer with the stack baked in.

Online installer

cd OneClickMediaSuite
./install.sh          # choose "Download latest" at the images prompt

Answers a handful of questions up front (VPN provider + credentials, paths, timezone, Jellyfin/qBittorrent logins), then runs unattended: Docker → folders → compose → API wiring → credentials summary.

Offline installer

./bundle.sh           # once, on any machine with docker + internet
# copy the whole folder to the target, then:
./install.sh          # choose "Use the bundled copy"

bundle/ carries all 13 container images (~1.7 GB) plus Docker Engine .deb packages for Ubuntu 24.04 — no internet needed on the target at all.

Bootable ISO

sudo apt install xorriso
./build-iso.sh        # produces oneclick-mediasuite-ubuntu.iso

A remastered official Ubuntu Server 24.04 ISO. Flash it to USB, boot, answer only the Ubuntu user + disk questions — the stack installs on first boot (or prompts on first login if no answers were baked in). The VPN, folder layout and API wiring are identical to the script installers.

Getting Cobalt Wolf onto your devices

The last, optional phase of every installer sideloads the latest Cobalt Wolf release APK over adb — to a Fire Stick over the network (classic Fire OS models only) or a phone/tablet over USB — and keeps offering more devices until you say no. The offline installer and the ISO carry the APK in bundle/, so it works without internet; the online installer downloads it at install time. On first launch, connect to your server and sign in with the Jellyfin admin account the installer created — Seerr and arr details can be set in the app's Services screen.

Prefer to set up the app yourself? Install it from the download page like normal and point it at your server — nothing about the app requires the suite.

Downloads

The three installers are attached to the GitHub Releases (tagged media-suite-*) and documented in the repository's installers/ folder — including SHA256SUMS.txt for verifying downloads and the join-iso.bat helper for rebuilding the ISO from its parts on Windows.
