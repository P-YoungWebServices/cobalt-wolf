Calendar & media manager

Cobalt Wolf talks to the whole *arr stack: Radarr and Sonarr for calendars and media management, qBittorrent for transfers, Bazarr for subtitles and Prowlarr for indexers.

Connecting services

Open service settings (phone: More → Services; TV: the services entry under the dashboard) and add each service:

ServiceNeedsUsed for
RadarrURL + API keyMovie calendar, media manager
SonarrURL + API keyEpisode calendar, media manager
qBittorrentURL + username + passwordDownloads monitor & control
BazarrURL + API keyWanted subtitles, provider search
ProwlarrURL + API keyIndexer health, stats, retests
API keys and passwords are encrypted at rest via the Android Keystore. Each service fails independently — a dead Sonarr won't take the Radarr calendar down with it.

Calendar

  • Merges upcoming episodes (Sonarr) and releases (Radarr) into one view.
  • Three modes: List, Week (Monday-first) and Month grid — the app fetches exactly the visible range.
  • Available on both phone and TV; on TV it gets its own top-bar entry.

Media manager (admin only)

Full control of Radarr movies and Sonarr series:

  • Browse the movie and series libraries each service manages.
  • Edit monitored status, quality profile, root folder and tags. Edits preserve fields the app doesn't model, so nothing is silently dropped.
  • Monitor seasons and episodes individually.
  • Rename files with a preview before committing.
  • Search & grab — automatic and interactive release searches; pick a release and grab it.
  • Manual import for files already on disk.
  • Delete — with the choice of removing files or just the record.

qBittorrent monitor

  • Live torrents/info + transfer/info polling while the screen is open.
  • Pause/resume torrents — uses the v5 API and falls back to the legacy endpoints on older qBittorrent.
  • Toggle alternative speed limits ("turtle mode").
  • Cookie-based auth with automatic re-login when the session expires.

Bazarr

  • The wanted list shows movies and episodes missing subtitles.
  • Search subtitle providers for an item and download a subtitle directly.

Prowlarr

  • Overview merging indexers, stats, auto-disable status and health.
  • Retest a single indexer or test them all; failure details from validation errors are surfaced.

Access control

The media manager, downloads monitor and service credentials are admin-only destinations — hidden and unreachable for regular users even though parts of the underlying screens are general-purpose. The calendar is available to everyone.
