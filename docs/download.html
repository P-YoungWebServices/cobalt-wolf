Install on a phone or tablet

Download the APK

On the device, tap Download APK above (or grab it from GitHub Releases).

Allow the install

Android will ask to allow installs from your browser or file manager — accept it. You can revoke the permission afterwards.

Connect to your server

Open Cobalt Wolf, enter your Jellyfin server address and sign in — or use Quick Connect. See the getting started guide.

Install on Android TV / Fire TV

The simplest option is a downloader app on the TV. Alternatively, install over adb from a computer:

# Android TV / Fire TV over network adb
adb connect <tv-ip-address>
adb -s <tv-ip-address> install cobalt-wolf-v0.1.1-beta.apk

On Fire TV, enable Developer options → ADB debugging and Apps from unknown sources first. The TV layout appears automatically — there's nothing to configure.

Staying up to date: releases are published on GitHub. Reinstalling a newer APK over the top keeps your settings, servers and profiles — your sign-in tokens live in the Android Keystore.
