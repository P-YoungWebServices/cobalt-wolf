The full package

OneClick Media Suite

Cobalt Wolf ships with a matching server installer. OneClick Media Suite turns a fresh Ubuntu 24.04+ machine into a complete, pre-wired Jellyfin + Servarr backend, then sideloads a preconfigured Cobalt Wolf onto your Fire Sticks and Android devices over adb.

Ask, and it arrives

Request a movie or episode in the app — Seerr approves it, Radarr/Sonarr find it, qBittorrent downloads it, and it lands in your Jellyfin library automatically. No manual steps, no API keys to copy.

Wired together for you

Prowlarr feeds indexers to the media managers, downloads import on hardlink-friendly paths, and Jellyfin's libraries watch for new files in real time — the fiddly integration work a DIY stack takes hours to get right.

Private by default

Torrent and indexer traffic runs through a Gluetun VPN tunnel (WireGuard or OpenVPN) with a self-healing watchdog that restarts it if it drops. Prefer not to? There's an explicit no-VPN mode too.

Couch-ready in one go

When the stack is up, the installer builds a Cobalt Wolf APK pre-loaded with your server's URLs and API keys, then pushes it to every Fire Stick and Android device you point it at.

Three ways to install — an online installer, a fully self-contained offline installer, or a bootable Ubuntu Server ISO that does the OS and the stack in one go.

Already running your own stack? You don't need it — Cobalt Wolf works with any Jellyfin 12.0+ server and services you already have.

One app, three jobs

Watch it. Run it. Manage it.

Most Jellyfin clients play media. Cobalt Wolf plays media, administers the server and manages the automation stack behind it — no switching between three apps.

▶A serious player

Direct play up to your device's limits with a graceful three-level fallback — direct play, on-device FFmpeg decode, then server transcode.

  • 4K, HDR10, HDR10+, HLG, Dolby Vision P5/P7/P8
  • H.264, HEVC, AV1, VP9
  • TrueHD Atmos, DTS-HD MA, DTS:X passthrough
  • ASS/SSA styling, PGS, SRT with delay offset

📺A real TV app

A dedicated 10-foot interface built with Compose for TV activates automatically on televisions — not a stretched phone layout.

  • D-pad focus model tuned for remotes
  • Frame-rate & HDR display matching
  • Home-screen channels where supported
  • Skip intro, next episode, ends-at clock

🛠Server in your pocket

Full admin dashboard for Jellyfin administrators, plus the whole *arr stack — from the same sign-in.

  • Sessions, users, tasks, logs, libraries, plugins
  • Seerr requests & approval queue
  • Radarr/Sonarr calendar & media manager
  • qBittorrent, Bazarr, Prowlarr
Best-for-the-device playback

The highest-quality path your hardware can handle

Every time you press play, Cobalt Wolf probes the device's decoders, display and audio output, then picks the best supported path — and falls back gracefully instead of failing.

  • Dolby Vision plays where the decoder and display support it; elsewhere it falls back to its HDR10/HLG/SDR base layer.
  • Lossless audio passthrough when the HDMI sink reports the format — otherwise clean PCM decode on-device.
  • Frame-rate matching on TV switches the output to the content's cadence; HDR is signalled only while HDR plays.
  • Stats overlay shows codec, bitrate, HDR type, audio output, channels and dropped frames in real time.

Android TV & Fire TV

Built for the couch, not ported to it

On a television, Cobalt Wolf swaps to a dedicated D-pad interface with its own navigation, focus model and player controls — same codebase, different experience.

  • Top-bar navigation — Home, Search, Seerr, Calendar and a More menu, always reachable.
  • Home-screen channels for Continue Watching and Recently Added on Android TV.
  • Remote transport keys — play/pause, fast-forward, rewind and stop just work.
  • Context menus on every poster: play, mark watched, favourite, queue.
